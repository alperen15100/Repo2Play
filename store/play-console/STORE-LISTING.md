# REPO2PLAY — GOOGLE PLAY LISTING

APP NAME

Repo2Play


SHORT DESCRIPTION

Build signed Android APK and AAB releases from GitHub on your phone.


FULL DESCRIPTION

Turn your Android GitHub project into a signed release
directly from your phone.

Repo2Play is a mobile Android release utility by Ecrin Labs.
Connect your own GitHub access, choose a repository and
branch, and start your release build.

KEY FEATURES

• GitHub repository to Android release
• Signed APK generation
• Play Store AAB generation
• NEW and UPDATE modes
• Project signing-key continuity
• Encrypted local Signing Vault
• Build status tracking
• Build history
• Release package download
• Mobile-first workflow
• Android Keystore-backed credential protection

NEW mode creates the initial project release.

Repo2Play can retain the project's signing identity
for later UPDATE builds, helping Android releases
maintain signing continuity.

Repo2Play is designed for Android developers,
independent makers and mobile-first creators.

Repo2Play does not guarantee Google Play acceptance.
Developers remain responsible for the applications
and content they publish.
