# Repo2Play — Play Store Listing

Developer: Ecrin Labs

## App name
Repo2Play

## Short description
Turn Android GitHub projects into signed APK and Play Store AAB releases.

## Full description
Repo2Play is a mobile release workspace for Android developers who build from GitHub.

Connect your GitHub account, choose an Android repository, select NEW or UPDATE, and start a release build directly from your phone.

Highlights:
- GitHub repository to signed Android release
- APK and Play Store AAB output
- NEW and UPDATE workflows
- Per-project signing-key continuity
- Encrypted on-device GitHub token storage
- Signing-key vault with JKS import and backup
- Build status and recent build history
- Build, signing, version and Play readiness reports

Repo2Play communicates directly with GitHub and GitHub Actions. Ecrin Labs does not operate a separate build-data backend for this app.
