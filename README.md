# Repo2Play V10 Clean Engine
Upload the whole package preserving folders. Run Actions > Repo2Play V10 Clean Engine > Run workflow, enter owner/repo and branch.
For private target repos create TARGET_REPO_TOKEN with read access.
Output artifact: Repo2Play-V10-Result containing APK, AAB and reports when build succeeds.
This engine diagnoses unsupported/broken repositories rather than claiming every GitHub repository can build.
Production signing identity continuity and secure customer credential storage must be added before commercial Play Store release.
