Repo2Play Privacy Policy

Developer: Ecrin Labs

Repo2Play helps users build Android projects through GitHub and GitHub Actions.

GitHub credentials

A GitHub personal access token entered by the user is encrypted locally using Android Keystore. Repo2Play uses the token only to authenticate requests the user initiates to GitHub. The token is not sent to a separate Ecrin Labs backend in this version.

Repository and build data

Repository identifiers, branch names, workflow inputs and build operations are transmitted to GitHub and GitHub Actions as necessary to provide the requested functionality. GitHub's own terms and privacy practices apply to GitHub services.

Signing keys

Repo2Play can keep a per-project signing key in an encrypted local vault to maintain Android update-signing continuity. A backup JKS may also be included in the release package downloaded by the user.

Analytics and advertising

This version contains no advertising SDK and no analytics SDK.

Data sale

Ecrin Labs does not sell user data collected by Repo2Play.

Deletion

Removing Repo2Play or clearing its app data removes locally stored token, build history and encrypted signing-vault data from the device.

Contact

For privacy questions, contact Ecrin Labs through the developer contact information shown on the Google Play listing.
